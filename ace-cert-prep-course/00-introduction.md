# Course Objectives

- **Deploy, operate, secure, and monitor enterprise solutions** on Google Cloud Platform to pass the Google Associate Cloud Engineer (ACE) certification exam
- Establish scalable resource hierarchies, billing exports, and fundamental IAM access policies
- Architect, provision, and automate compute resources using Compute Engine and Terraform
- Select, configure, and manage relational, NoSQL, and object storage solutions
- Build, deploy, and scale containerized workloads using Artifact Registry and GKE Autopilot
- Deploy serverless microservices and event-driven architectures with Cloud Run and Eventarc
- Implement enterprise observability, custom logging sinks, and alert policies using Cloud Operations
- Design secure networking, global load balancing, firewalls, and hybrid cloud connectivity
- Enforce least-privilege security using custom roles, service account impersonation, and Workload Identity

# Prerequisites

- **Command Line:** Proficiency with Linux command-line tools (bash, environment variables, SSH)
- **Networking:** Fundamentals of IPv4 addressing, CIDR blocks, DNS, and HTTP/HTTPS protocols
- **Cloud Basics:** General understanding of public cloud concepts (IaaS, PaaS, SaaS)
- **Version Control:** Basic familiarity with Git commands (`clone`, `checkout`) and JSON/YAML file formats
